# Aurelle — стоматологическое ателье (концепт)

Статический концепт-сайт вымышленной премиальной стоматологии в Бишкеке. Эстетика «тихой роскоши»: слоновая кость, графит, шампань; Cormorant Garamond + Manrope; медленная, «дорогая» анимация.

> Aurelle — вымышленный бренд. Имена врачей, отзывы и цены — демонстрационные. Форма записи ничего не отправляет.

## Что внутри

- Прелоадер с прорисовкой монограммы и счётчиком.
- Закреплённый (pinned) первый экран: чертёж импланта (винт, абатмент, коронка) собирается по скроллу и из линий «blueprint» превращается в светящийся объект.
- Посимвольное появление заголовков, подсветка текста по словам, параллакс, счётчики.
- Горизонтальный скролл услуг (на телефоне — свайп), 3D-облако точек на canvas, микроскоп-чертёж, который рисуется при прокрутке.
- Слайдер «до/после», путь пациента, цены, отзывы, форма записи с валидацией.
- Плавный скролл (Lenis), магнитные кнопки и кастомный курсор на десктопе, зерно и мягкие световые градиенты.
- Учитывается `prefers-reduced-motion`: анимации отключаются, сайт показывается в статичном виде. Без доступа к CDN сайт тоже остаётся рабочим (статичный режим).

## Структура

```
index.html
assets/css/style.css
assets/js/visuals.js   — генерация SVG-портретов, улыбки «до/после», облака точек
assets/js/main.js      — анимации (GSAP + ScrollTrigger), Lenis, курсор, форма
```

Библиотеки подключаются с CDN с фиксированными версиями: GSAP 3.12.5, ScrollTrigger 3.12.5 (cdnjs), Lenis 1.1.13 (unpkg). Сборка не нужна. Внешних изображений нет.

## Как открыть локально

```bash
cd dental-clinic-site
python3 -m http.server 8080
# открыть http://localhost:8080
```

Можно открыть `index.html` и напрямую из файловой системы, но локальный сервер ведёт себя ближе к GitHub Pages.

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → выбрать ветку и папку `/ (root)`.
